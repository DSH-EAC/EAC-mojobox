# Mojobox 框架验收

日期：2026-09-30。范围：收纳、静态检验、展示、原始归档下载。环境：Windows，Node 24.21.0。

## 结论

三个框架阶段已完成。开发者可提交收录记录和符合当前薄 Feature Pack 规范的归档，系统检查、生成目录及报告，网站展示并提供相同字节下载。没有正式内容时保持空目录，测试演示独立构建。

该结论不是“生产整合包已可用”或“已经部署”。正式收录目前为 0，真实整合包适配和宿主搭载未执行。

## 边界与限制

- 当前只支持收录规范声明的薄 Feature Pack v1，不能接收任意 npm tgz、内嵌插件或其他格式。
- 自动检查不解析插件来源、不核验作者身份、不执行插件；许可证与作者来源需要维护者审阅。
- 下载交给浏览器原生行为；服务器上线后丢失文件时，网站不实现自定义下载重试或错误弹窗。
- CI 配置已更新并核对，本地等价命令通过；没有推送，所以没有声称远端 GitHub Actions 已运行。
- 尚未公网部署，也未验证其他浏览器或操作系统。IME/剪贴板失败采用定向测试，不冒充实际系统权限故障复现。
- 外层 EAC 仓库及日常 Profile 未因本阶段而修改。

## 后续顺序

1. 适配用户指定的真实整合包：记录原始产物、摘要和具体格式差异，开发者产物变化时保留改动说明。
2. 按真实归档加入收录记录，重新构建并核对下载摘要。
3. 在隔离宿主环境搭载测试，记录真实安装/重启及失败结果；问题归属宿主或整合包，不在 Mojobox 复制安装器。
4. 外部发布或部署另按用户授权执行。
